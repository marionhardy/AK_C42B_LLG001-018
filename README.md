# AK_C42B_LL001-027
## Context

RNA sequencing data set of C42B cells treated for 1 to 9 days with different doses of Olaparib.

## Content

- metadata.xlsx : Contains the annotation for the raw files.
- DESeq2_1-18.R : Initial processing of the raw count files received from the bioinformatics core. Will generate the processed DESeq objects.
- C42B_1-18_for_publication.Rmd: Overall report on the data.
- /figures/ : folder containing all generated figures.
- /for_pub/ : folder for the figures used in the publication.
